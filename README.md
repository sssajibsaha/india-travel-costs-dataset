# India travel costs dataset (2026)
Planning figures behind the [India Trip Budget Calculator](https://indiatourblog.com/india-trip-budget-calculator/).
- `budget_tiers_inr.csv` per-day INR ranges by tier (backpacker/mid/luxury)
- `destinations_cost_and_season.csv` regional cost multiplier + best/shoulder/avoid by month
- `evisa_fees_usd_2026.csv` official e-Tourist visa fees (+3% bank charge)
Sources: Government of India e-Visa fee schedule; site estimates. Planning ranges, not quotes.
